# Barbearia Navalha

Site estático de uma barbearia fictícia, desenvolvido com HTML e CSS. A página apresenta a barbearia, seus serviços e um formulário de agendamento.

## Funcionalidades

- Cabeçalho com logo e navegação pelas seções da página.
- Seção principal com chamada para agendamento.
- Apresentação da barbearia.
- Cards de serviços: corte de cabelo, barba e combo.
- Formulário com campos para contato, serviço e horário desejados.
- Rodapé com informações de contato, redes sociais e horário de funcionamento.
- Estilos para diferentes larguras de tela.

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox e media queries)
- Google Fonts: Inter, Open Sans e Playfair Display SC

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador.

O projeto não requer instalação de dependências nem etapa de build. Para carregar as fontes do Google Fonts, é necessária uma conexão com a internet.

## Observação sobre o formulário

O formulário está estruturado e estilizado no front-end, mas ainda não está integrado a um servidor ou serviço de agendamento. É necessário configurar o processamento dos dados antes de utilizá-lo para receber reservas reais.
